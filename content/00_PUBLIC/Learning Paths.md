# Learning Paths

Gunakan halaman ini bila kamu ingin belajar berurutan, bukan sekadar mencari satu istilah.

## Fondasi umum
[[10_FOUNDATION/01 Cell Tissue Homeostasis]] → [[10_FOUNDATION/02 Injury Inflammation Healing]] → [[10_FOUNDATION/03 Anatomy Surface Anatomy]] → [[10_FOUNDATION/04 Physiology Core]] → [[20_MOVEMENT/01 Biomechanics Kinesiology]] → [[20_MOVEMENT/02 Neuroscience Motor Control]].

## Shoulder
Anatomi/surface anatomy → biomekanik shoulder → [[30_ASSESSMENT/15 Shoulder Special Tests]] → [[33_SPECIAL_TEST_CARDS/01 Shoulder Special Test Procedures]] → kondisi shoulder di [[50_MSK/00 MSK Index]] → [[40_INTERVENTION/09 Manual Therapy Mobilization]] → [[40_INTERVENTION/02 Strengthening]].

## Knee
Biomekanik lower limb → [[30_ASSESSMENT/17 Hip Knee Special Tests]] → [[33_SPECIAL_TEST_CARDS/03 Hip Knee Special Test Procedures]] → OA/ACL/TKR di [[50_MSK/00 MSK Index]] → strengthening → gait/return to function.

## Stroke
[[20_MOVEMENT/02 Neuroscience Motor Control]] → [[60_NEURO/01 Stroke]] → [[30_ASSESSMENT/08 Reflex Examination]] → sensory/coordination/balance/gait → [[40_INTERVENTION/10 PNF]] / [[40_INTERVENTION/11 Bobath NDT]] → task-specific training → outcome measures.

## Spinal Cord Injury
Neuroanatomi spinal cord → [[60_NEURO/02 Spinal Cord Injury]] → [[31_OUTCOME_PROCEDURES/01 ISNCSCI ASIA Examination]] → [[31_OUTCOME_PROCEDURES/03 SCIM III]] + [[31_OUTCOME_PROCEDURES/04 Function in Sitting Test FIST]] → transfer/ambulation → strength/endurance → participation.

## Respiratory
Respiratory physiology → [[30_ASSESSMENT/20 Cardiorespiratory Examination]] → respiratory lab skills → obstructive/restrictive/infectious conditions di [[70_CARDIORESP/00 Cardiorespiratory Index]] → [[40_INTERVENTION/13 Cardiorespiratory Breathing Airway Clearance]] → 6MWT/functional monitoring.

## Pediatri
Normal growth and motor learning → [[30_ASSESSMENT/21 Pediatric Examination]] → pediatric outcome procedures → kondisi di [[80_PEDIATRIC/00 Pediatric Index]] → NDT/task facilitation/exercise → participation.

## Geriatri
Physiology of aging → sensory/balance/gait → [[30_ASSESSMENT/22 Geriatric Examination]] → outcome measures → [[81_GERIATRIC/00 Geriatric Index]] → strength/balance/endurance/fall prevention.
