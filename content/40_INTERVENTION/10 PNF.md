## Konsep

PNF menggunakan diagonal/spiral movement, manual contact, resistance, stretch, verbal/visual cue, dan timing untuk memfasilitasi motor performance.

## Patterns

Upper extremity D1/D2 flexion-extension. Lower extremity D1/D2 flexion-extension. Scapular dan pelvic patterns menjadi dasar trunk dan limb integration.

## Teknik umum

Rhythmic initiation: passive → active-assisted → active → resisted untuk mengajarkan pattern dan mengurangi rigidity.

Repeated contractions: stimulus berulang pada titik weakness untuk meningkatkan activation.

Slow reversal/dynamic reversal: alternating agonist-antagonist tanpa relaxation penuh.

Hold-relax: isometric contraction kemudian bergerak ke range baru untuk mobility bila sesuai.

Contract-relax: isotonic contraction diikuti movement ke range baru.

Rhythmic stabilization: alternating isometric resistance untuk stability.

## Aplikasi

Pilih berdasarkan goal, bukan diagnosis semata. Misalnya pelvic pattern untuk gait control, rhythmic initiation untuk pasien sulit memulai gerak, atau stabilization untuk trunk control.

## Clinical Deep Dive

## PNF operasional

PNF menggunakan spiral-diagonal pattern, manual contact, stretch, resistance, verbal/visual cue dan timing untuk memfasilitasi motor output.

### Upper limb patterns

D1 flexion secara umum mengarah flexion-adduction-external rotation dengan hand components; D1 extension kebalikan. D2 flexion mengarah flexion-abduction-external rotation; D2 extension kebalikan. Detail wrist/finger mengikuti pattern materi ARM PATTERNS.

### Lower limb

D1 flexion dan D2 flexion/extension menggabungkan hip-knee-ankle components dalam diagonal. Gunakan materi LEG PATTERNS untuk posisi detail.

### Techniques

Rhythmic initiation: passive → active-assist → active → resisted untuk belajar movement. Repeated contraction untuk meningkatkan activation. Slow reversal/alternating isotonic melatih agonist-antagonist control. Hold-relax/contract-relax untuk mobility. Rhythmic stabilization untuk co-contraction/postural control.

### Clinical use

Pilih technique berdasarkan problem. Jangan memberi seluruh pattern bila goal hanya transfer. PNF sebaiknya masuk ke task: rolling, reach, gait, trunk control.

### Outcome

Perubahan activation, ROM, task quality dan assistance segera setelah technique lalu carryover ke task.
