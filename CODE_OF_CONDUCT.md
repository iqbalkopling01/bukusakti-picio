# Code of Conduct

Diskusi harus fokus pada isi, evidence, keselamatan, dan kejelasan materi. Kritik diperbolehkan dan diharapkan, tetapi serangan personal, penghinaan, doxxing, atau penyebaran data pasien tidak diterima.

Jika sebuah koreksi menyangkut keselamatan klinis, jelaskan masalahnya secara spesifik dan sertakan sumber bila memungkinkan.
