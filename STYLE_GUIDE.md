# Style Guide

## Bahasa

Gunakan Bahasa Indonesia yang ringkas dan klinis. Istilah Inggris boleh dipertahankan jika memang lazim digunakan dalam fisioterapi, misalnya `weight shifting`, `end feel`, `gait speed`, atau nama outcome measure.

## Heading

Gunakan heading yang bisa dipindai cepat. Hindari paragraf raksasa.

## Pemeriksaan

Tulis: **tujuan → indikasi → posisi pasien → posisi pemeriksa → langkah → positif/hasil → interpretasi → limitations/safety**.

## Intervensi

Tulis: **target → setup → pelaksanaan → dose/parameter → progression → regression → precaution → reassessment**.

## Kondisi

Tulis sebab-akibat, bukan daftar hafalan. Contoh: `cartilage loss → altered load distribution → pain/effusion → quadriceps inhibition → reduced function`.

## Case pattern

Jangan tulis nama, inisial spesifik yang dapat dilacak, tanggal lahir, nomor rekam medis, alamat, nomor telepon, rumah sakit, nama klinisi, foto pasien, atau tanggal perawatan spesifik.

## Wikilinks

Gunakan wikilink untuk konsep yang sudah memiliki note sendiri. Jangan membuat duplikasi penjelasan panjang jika cukup dengan ringkasan + link.
